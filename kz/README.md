# «Как здорово!» 7–9 — страницы классов

Закрытые от оглавления страницы (их нет в `index.html`, у страниц `noindex`): ссылку получают только ученики класса.

| Класс | Страница | Данные |
|---|---|---|
| 7 | `kz/7-927feb/` | `kz/7-927feb/data.json` |
| 8 | `kz/8-821dfa/` | `kz/8-821dfa/data.json` |
| 9 | `kz/9-ac8433/` | `kz/9-ac8433/data.json` |

Адрес: `https://metaphys23.github.io/tezaurus/kz/7-927feb/` (и так далее).

## Как устроено
- `index.html` в папке класса одинаковый у всех; всё содержимое страница читает из `data.json` рядом с собой (`kz/class.js`, стиль `kz/class.css`).
- Чтобы поменять страницу, достаточно править `data.json` — разметку трогать не нужно. Редактор страницы можно сделать поверх этого файла.
- `kz/p/<id>/` — HTML-презентации (движок `kz/p/deck/`: ленивые слайды, писалка, заметки учителя по клавише N).
- `kz/f/<класс>/` — PDF для учеников (ученические версии, без ответов).
- Тесты-самопроверки — обычные тесты движка `exam.html` (`tests/kz7-t1-1107.json` и т. п., собирает `tools/build_tests_kz79.py`; `grading: client` — это тренировка).

## Формат data.json
```json
{
  "title": "Как здорово! 7 класс",          // заголовок страницы
  "kicker": "Физика · 7 класс",             // строка над заголовком
  "updated": "2026-11-06",                  // дата обновления (ГГГГ-ММ-ДД)
  "notice": "Текст плашки вверху",          // необязательно
  "homework": [                              // новое — первым
    { "due": "2026-11-14", "title": "Тема",
      "read":  ["§ 19 «Инерция» — прочитать"],
      "solve": ["Листок …: **№ 1–8**"],
      "note":  "необязательный абзац",
      "files": [ { "type": "hw", "title": "ДЗ (PDF)", "url": "../f/7/dz-k-14-11.pdf" } ] }
  ],
  "tests":   [ { "type": "test", "title": "…", "url": "../../exam.html?t=kz7-t1-1107" } ],
  "lessons": [ { "date": "2026-11-07", "topic": "Тема урока", "note": "…", "files": [ … ] } ],
  "folder": "Текст со ссылкой [на Google Диск](https://…)"
}
```
- `type` у файла: `presentation`, `sheet`, `hw`, `sr`, `test`, `trainer`, `doc`, `link` — от него зависит цветная метка.
- У любого задания, файла, урока можно поставить `"hidden": true` (скрыть) или `"show_from": "2026-11-07T15:00"` (показать с этого момента). Это только скрывает строку на странице: сам файл в публичном репозитории доступен по прямой ссылке, поэтому СР и учительские файлы в репозиторий не кладём до проведения / вообще.
- В текстах работает `**жирный**`, `*курсив*`, `[текст](ссылка)`. Ссылки внутри сайта — относительные, как в примере.
