# Тезаурус

Статические страницы для учеников (GitHub Pages): открываются без входа и регистрации.

- `index.html` — оглавление
- `slozhenie-sil.html` — «Сложение сил: проекции» (9 класс)
- `inzh-shim.html`, `inzh-svetodiod.html` — инженерные тренажёры (ШИМ; светодиод и резистор)
- `inzh-blink.html`, `inzh-ogni.html`, `inzh-millis.html`, `inzh-rgb.html`, `inzh-7seg.html` — тренажёры кружка Arduino (мигание и delay; бегущие огни; таймеры millis; RGB и Serial; 7-сегментный индикатор). Собираются из исходников хаба `AI/courses/lim/trenazhery/` (`build.py`), скетчи на страницах компилируются под Nano
- `oge-kinematika.html` — «ОГЭ · Кинематика» (9 класс, 5 попыток) — прежняя отдельная страница
- `exam.html?t=<id>` — общий движок тестов: читает `tests/<id>.json`
  - Т1 `exam-topic` — проверка по выбору ученика (у задания или у части), попытки без ограничения
  - Т2 `exam-section` — проверка после сдачи всей работы, лимит попыток
  - ДЗ `dz` — одна сдача; задания с автопроверкой или «ответ + фото» (kind `text`), без шкалы — отметку ставит учитель (пример `dz-10fm-okruzhnost`)
  - Т3 `exam-mock` — как Т2 плюс мягкий таймер (по истечении — предупреждение)
  - все задания на одной странице прокруткой; липкая панель с номерами и статусами; справочные данные вверху
  - Т2/Т3: после сдачи вопрос «финальная попытка?»; после финальной — решения всех заданий (`tests/<id>.solutions.json`) и галочки «Выполнил работу над ошибками» → рейтинг ученика (нужен второй приём `TR_ENDPOINT_V2`)
- `tests/*.json` — тесты (формат — `tests/test.schema.json`), `tests/fig/` — рисунки
- `assets/` — движок (`exam.js`, `exam.css`), `assets/katex/` — KaTeX 0.16 (MIT) для формул в решениях
- `tools/e2e_exam.py` — проверка движка в headless Chromium на моке приёма ответов
- `config.js` — адреса приёма ответов: `TR_ENDPOINT` (прежний Apps Script) и `TR_ENDPOINT_V2` (приём v2 для `exam.html`)

Ответы уходят POST-запросом в веб-приложение учителя; на странице собирается только фамилия и имя.
Протокол отправки у `exam.html` тот же, что у `oge-kinematika.html`.
